# متابع النادي 🏋️

### تطبيق ويب لمتابعة حضور النادي والالتزام بالتمارين

---

## عن المشروع 📌

متابع النادي هو تطبيق ويب بسيط يساعد على تسجيل حضور النادي ومتابعة الالتزام والتقدم خلال فترة زمنية مدتها ستة أشهر.

تم تصميم التطبيق ليكون سهل الاستخدام، بحيث يمكن تسجيل حالة كل تمرين بسرعة ومتابعة الإحصائيات والتقدم بشكل واضح.

---

## المميزات ✨

- لوحة تحكم لعرض إحصائيات الحضور والتقدم 📊
- جدول تدريبي لمدة ستة أشهر 📅
- تسجيل الحضور بسهولة ✅
- تسجيل عدم الحضور ❌
- حساب نسبة الالتزام تلقائيًا 📈
- عرض الإحصائيات الشهرية
- متابعة التقدم بشكل واضح
- حفظ البيانات تلقائيًا داخل المتصفح 💾
- الوضع الليلي والنهاري 🌙
- تصميم متجاوب مع الجوال والكمبيوتر 📱

---

## جدول التمارين 🗓️

الجدول الأساسي للتطبيق يتضمن ثلاثة أيام تدريب أسبوعيًا:

- السبت
- الاثنين
- الأربعاء

### فترة المتابعة

**سبتمبر 2026 — فبراير 2027**

---

## طريقة تسجيل الحضور 📝

يمكن تحديد حالة كل موعد من خلال خانة الحالة:

- **✓ حضرت** — تظهر الخانة باللون الأخضر.
- **✕ لم أحضر** — تظهر الخانة باللون الأحمر.
- **بدون تحديد** — لم يتم تسجيل الحالة بعد.

---

## الإحصائيات 📊

يحسب التطبيق بشكل تلقائي:

- إجمالي مواعيد التمارين
- عدد مرات الحضور
- عدد مرات عدم الحضور
- نسبة الحضور
- نسبة التقدم
- الإحصائيات الخاصة بكل شهر

---

## التقنيات المستخدمة 🛠️

- HTML
- CSS
- JavaScript
- LocalStorage

---

## حفظ البيانات 💾

يتم حفظ بيانات الحضور محليًا داخل المتصفح باستخدام:

`LocalStorage`

ولا يحتاج التطبيق إلى إنشاء حساب أو استخدام قاعدة بيانات خارجية.

---

## تشغيل المشروع 🚀

يمكن تشغيل المشروع مباشرة من خلال فتح الملف:

`index.html`

لا يحتاج المشروع إلى تثبيت مكتبات أو برامج إضافية.
